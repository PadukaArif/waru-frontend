# DATABASE SCHEMA

## Overview

Dokumen ini menjelaskan struktur database WARU menggunakan MongoDB.

Database dirancang berdasarkan:

* PROJECT_OVERVIEW.md
* BUSINESS_FLOW.md
* USER_FLOW.md
* ROLE_PERMISSION.md
* FRONTEND_ARCHITECTURE.md
* COMMUNICATION_FLOW.md
* SECURITY_ARCHITECTURE.md
* BACKEND_REVIEW.md

Prinsip utama database:

* Simple
* Consistent
* Secure
* Maintainable
* Easy to understand
* Tidak overengineering

Database menjadi sumber kebenaran utama untuk data operasional WARU.
